## Getting Started

To run the project locally:

1. Prerequisities:
   - Node.js & npm - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)
   - Java 21+ and Maven

2. Clone the repo and install dependencies:

```sh
npm install
```

3. Start the development server:

```sh
npm run dev
```

4. Start the backend:

```sh
cd backend
mvn spring-boot:run
```
